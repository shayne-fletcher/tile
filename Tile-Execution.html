Run a gather schedule.

runReduce :: Schedule String -> [(String, Int)] -> (Int -> Int -> Int) -> String -> IO () Source #

Run a reduce schedule.

Leaf values flow toward the root and are combined at each node.

runScatter :: Show a => Schedule String -> [(String, a)] -> String -> IO () Source #

Run a scatter schedule.

The root starts with a value for each destination. At each hop, the payload is partitioned by the routed subtree below each child.
