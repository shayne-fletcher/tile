Description

These functions interpret schedules as pure results. They provide a denotational reference for concurrent interpreters.

broadcastResult :: Ord m => Schedule m -> m -> p -> Map m p Source #

Delivery state after broadcast execution.

The result includes the root, which holds the payload from the start. This records reachable members, not only receivers of schedule steps.

reduceResult :: Ord m => Schedule m -> m -> Map m v -> (v -> v -> v) -> v Source #

Result of reducing values along a schedule that flows toward the root.

Precondition: the value map contains every member reachable from the root.

gatherResult :: Ord m => Schedule m -> m -> Map m v -> [(m, v)] Source #

Result of gathering values at the root.

Values are returned in preorder over the reversed convergence tree.

Precondition: the value map contains every member reachable from the root.

scatterResult :: Ord m => Schedule m -> m -> [(m, p)] -> Map m p Source #

Result of scattering destination-specific payloads.

Only payloads whose destinations are reachable from the root are delivered.
