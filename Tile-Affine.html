Description

An affine rank space maps logical coordinates to ranks using an offset and per-dimension strides. Slicing operations preserve the affine representation.

Affine rank spaces

data AffineRankSpace Source #

An affine map from logical coordinates to ranks.

For a coordinate coord, the rank is:

offset + sum (zipWith (*) coord strides)
