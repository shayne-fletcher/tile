Tile.Execution.Concurrent

Description

These functions interpret schedules using lightweight Haskell concurrency through channels and forked threads. The run* forms return the observed result without tracing; the run*WithTrace forms also report structured trace events. Their correctness contract is stated by the pure functions in Tile.Execution.
